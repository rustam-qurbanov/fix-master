# 🌌 Шпаргалка по скиллам Gemini (Antigravity)

Все скиллы, доступные агенту Gemini (Antigravity), делятся на два типа в зависимости от источника:
1. **Встроенные плагины (Plugins)** — идут в комплекте с ИИ-ассистентом Antigravity, лежат в папке конфигурации плагинов (`~/.gemini/config/plugins/`).
2. **Глобальные внешние скиллы (Skills CLI)** — скачаны из реестра в общую папку пользователя (`~/.agents/skills/`) с помощью CLI-утилиты `find-skills`.

---

## 🛠️ Глобальные внешние скиллы (Скачаны в `~/.agents/skills/`)

| Команда | Что делает | Когда использовать |
| :--- | :--- | :--- |
| **`/ui-ux-pro-max`** | Интеллектуальный помощник UI/UX (поиск практик, генерация дизайн-систем, шрифтов) | Когда нужно продумать дизайн-систему, сетку, подобрать цвета или шрифтовые пары |
| **`/ckm-design`** | Генератор логотипов, макетов и SVG-иконок с помощью ИИ | Когда требуется сгенерировать логотип или кастомные SVG-иконки для интерфейса |
| **`/ckm-brand`** | Создание фирменного стиля и брендбуков (CIP) | Когда нужно разработать общую визуальную концепцию бренда и его атрибутов |
| **`/ckm-ui-styling`** | Стилизация готовых веб-компонентов и интерфейсов | Когда нужно применить сложные стили (например, Glassmorphism, неоморфизм) к элементам |
| **`/ckm-design-system`** | Разработка, документирование и сборка дизайн-систем | Для сборки, структурирования и экспорта токенов дизайн-системы |
| **`/ckm-banner-design`** | Генерация баннеров, обложек и промо-графики | Когда нужно создать промо-материалы или графические баннеры |
| **`/ckm-slides`** | Генератор макетов для презентаций и слайдов | При проектировании структуры и визуального оформления слайдов |
| **`/find-skills`** | Менеджер поиска, установки и обновления готовых скиллов | Когда нужно найти и установить новый скилл в систему |

## 🌐 Веб-разработка, отладка и аудит (Встроенные плагины)

| Команда | Что делает | Когда использовать |
| :--- | :--- | :--- |
| **`/modern-web-guidance`** | Консультирует по современным стандартам HTML, CSS и JS | Когда нужно оптимизировать CSS, использовать современные веб-API или сверстать сложный UI |
| **`/a11y-debugging`** | Аудит доступности веб-страниц по стандартам web.dev | Перед выпуском фичи, чтобы убедиться в доступности интерфейса (семантика, контрастность, ARIA) |
| **`/debug-optimize-lcp`** | Поиск узких мест LCP и оптимизация скорости загрузки | Когда первый экран страницы загружается медленно (оптимизация Core Web Vitals) |
| **`/memory-leak-debugging`** | Поиск и устранение утечек памяти в JS / Node.js | При высоком потреблении памяти процессом или зависании приложения |
| **`/chrome-extensions`** | Разработка и отладка расширений для Google Chrome | При создании, редактировании или отладке браузерных расширений |
| **`/chrome-devtools`** | Отладка веб-страниц через DevTools и автоматизация браузера | Для автоматических проверок DOM, чтения консоли браузера и поиска ошибок |

## ☁️ Базы данных, Firebase и мобильная разработка (Встроенные плагины)

| Команда | Что делает | Когда использовать |
| :--- | :--- | :--- |
| **`/firebase-firestore`** | Проектирование БД Firestore, настройка индексов и запросов | При проектировании схемы данных в Firestore, написании запросов и правил безопасности |
| **`/firebase-auth-basics`** | Интеграция авторизации пользователей через Firebase Auth | При добавлении входа в приложение (email, Google, сессии) |
| **`/firebase-data-connect`** | Разработка реляционных схем БД в PostgreSQL через SQL Connect | При проектировании реляционных баз данных и написании мутаций |
| **`/firebase-security-rules-auditor`** | Анализ и повышение безопасности правил Firestore/Storage | Перед релизом для проверки правил доступа к базе данных на уязвимости |
| **`/firebase-basics`** | Инициализация и настройка CLI Firebase | При первом развертывании инфраструктуры Firebase или инициализации проекта |
| **`/android-cli`** | Сборка, отладка и управление SDK Android через консоль | При работе с Android-сборками, проверке эмуляторов или компиляции APK |
| **`/xcode-project-setup`** | Интеграция Swift Packages и настройка `.pbxproj` для iOS | Для подключения iOS-зависимостей и настройки проекта Xcode |
